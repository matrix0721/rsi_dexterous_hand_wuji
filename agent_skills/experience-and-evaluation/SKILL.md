# Experience and evaluation

`ctx.remember(text, evidence=[ids], status='observed')` records an event with
observed/hypothesized/confirmed/refuted status. Keep proposed interpretation
separate from measurements. Save failed stages as well as successful segments.
Use frozen controller files and workstation layout notes for comparisons.

Physical trials do not have a simulator reset or seed that reconstructs a layout.
Record placements, hardware/model/calibration versions and intervention. Do not
inherit a prior task's success or call a mock trial physical success. Record model
token/cost information only if provided by the actual model host; missing is unknown.
