# Benchmark generation

For a hardware task define object/fixture identities, starting layout photographs,
measurable goal, allowable intervention and trial metadata. Express actions as a
Python controller or hierarchical JSON recipe; separate task goal from the action
sequence. Keep held-out physical placements outside controller tuning.

This is a specification workflow. The project does not manufacture new physical
scenes, teleport objects, import simulator success or generate an automatic real
benchmark. Installation/calibration changes and manual resets must be recorded.
Only run the physical experiments requested by the user; no mandatory test matrix.
